# enterprise-network-cpk
Enterprise network simulation and documentation project featuring complex topologies in Cisco Packet Tracer.

The goal of this project is to demonstrate my technical expertise in network design and documentation, balancing current organizational needs with long-term scalability and resilience.

Please note that RUNA S.R.L. is a fictitious enterprise invented solely for this project. It does not represent any real company, and all requirements, topologies, and scenarios described here were defined for academic and simulation purposes.
